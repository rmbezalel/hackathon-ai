# Hackathon AI

Starter repository for the hackathon AI project.

## Structure

- `frontend/` — user interface
- `backend/` — application backend
- `modules/document_processing/` — document ingestion and processing
- `modules/retrieval/` — search and retrieval
- `modules/ai_analysis/` — AI-powered analysis
- `tests/` — automated tests
- `data/` — project data

## Setup

Install dependencies with `pip install -r requirements.txt` after adding packages to `requirements.txt`.
